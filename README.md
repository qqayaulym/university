Это мой курсовой проект! Вдохновилась каналом для активностей АЙТУ, в которую кидают разные активности за которые дают соц гпа. По сути мне этот телеграм канал нрав, но так как этот канал не специализируется не только на этом, в нем очень много спама этим. Типа там же не только это публикуют но и расписание и всякое важное. Так что разгрузить таким образом решила. Потому что тут будут фильтры, только активности, слежка за своим СоцГПА, красивый, удобный интерфейс.
